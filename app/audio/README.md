# קבצי שמע

כאן שמים הקלטות שמתנדבים מקליטים פעם אחת – וכל המשתמשים שומעים אותן.

- `am/` – אמהרית, `he/` – עברית
- שם הקובץ = ה-`key` מתוך `content.js`, בסיומת `.mp3`. דוגמאות:
  - `am/family.mp3` – "ለቤተሰብ ይደውሉ"
  - `am/mda.mp3` – "አምቡላንስ"
  - `am/lesson-answer-1.mp3` – הצעד הראשון בשיעור "לענות לשיחה"
  - `am/done.mp3`, `am/sent.mp3`, `am/noFamily.mp3`, `am/time-morning.mp3` ...
- קבצים קצרים (2–6 שניות), קול רגוע ואיטי.
- אין קובץ? האפליקציה תנסה הקראה אוטומטית, או הקלטה אישית ממסך ההגדרות.
