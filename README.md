# እርዳታ · עזרה

עוזר קולי באמהרית למבוגרים יוצאי אתיופיה שמתקשים בעברית, לא קוראים וכותבים, ולא רגילים לטכנולוגיה.
מבוסס על התכנון "קול בשבילך / እርዳታ": **לא צריך לדעת לקרוא. מספיק לדבר ולצלם.**

> "צלם מסמך בעברית או שאל שאלה באמהרית, וקבל הסבר פשוט בשפה שלך."

## מה יש כאן

| תיקייה | מה זה | עלות |
|---|---|---|
| `app/` | אתר קולי שמותקן על מסך הבית (PWA) | 0 ₪ – GitHub Pages |
| `worker/` | שרת קטן שמחזיק את מפתחות ה-AI: קורא מסמך, מבין שאלה, מפיק קול אמהרי | 0 ₪ – שכבות חינמיות |
| `bot/` | בוט וואטסאפ שמעביר פניות למתנדבים אנושיים ("עזרה מאדם") | 0 ₪ בהיקף קטן, לבדוק תמחור |

### מסך הבית – שלוש פעולות בלבד
- **📷 לצלם מסמך:** מכתב מביטוח לאומי, עירייה, קופת חולים, הודעת תור, חשבון, הזמנה לחתונה.
  מקבלים: 🔊 הסבר קולי קצר באמהרית, וכרטיסים עם אייקונים: 📅 תאריך · 🕖 שעה · 📍 מקום · 💰 סכום · ⏰ עד מתי · 👉 מה לעשות.
- **🎤 לשאול:** נוגעים, מדברים באמהרית, נוגעים שוב. אפשר לשאול גם על המסמך שצולם ("מתי זה?").
- **🙋 עזרה מאדם:** שיחה או וואטסאפ לבן משפחה / מתנדב, כולל התמונה ומה שהמערכת הבינה.

ובשורה קטנה: 👨‍👩‍👧 משפחה (חיוג בתמונה) · 🚑 חירום · 💊 תרופות לפי 🌅☀️🌇🌙 · 🎓 שיעורים קוליים (כולל "להיזהר מרמאים").

### בטיחות (מתוך התכנון)
- המודל מחלץ **רק מה שכתוב**. מה שחסר נאמר במפורש ("הכתובת המלאה לא כתובה").
- תמונה לא ברורה → מבקשים לצלם שוב, לא מנחשים.
- תרופות/מינונים, משפט, חובות, קנסות, קיצוץ קצבה → `review_required` → כפתור 🙋 מהבהב.
- בקשת קוד / כרטיס אשראי / תשלום דחוף בקישור → ⚠️ אזהרת הונאה.
- שאלה שנשמעת כמו מצב חירום → כפתור 🚑 101.
- המערכת לא מתיימרת לגשת לקופת חולים / ביטוח לאומי.
- תאריכים נאמרים "בלוח הלועזי" כדי שלא יתבלבלו עם הלוח האתיופי; שעות נאמרות **בשעון האתיופי** (19:30 → "ከምሽቱ አንድ ሰዓት ተኩል"). ⚠️ זו החלטה שחייבים לאמת עם המשתמשים.

## הפעלה – שלב אחר שלב

### שלב 1: האתר במצב הדגמה (בלי שום מפתח)
כל עוד `app/config.js` ריק, האתר מחזיר תשובות לדוגמה. זה בדיוק מה שהתכנון ממליץ: **לבדוק קודם את החוויה עם מבוגרים אמיתיים, לפני הטכנולוגיה.**
```bash
cd app && python3 -m http.server 8000      # http://localhost:8000
```
פרסום חינם: למזג ל-`main` → ב-GitHub: **Settings → Pages → Source: GitHub Actions** → הכתובת: `https://<user>.github.io/git-test/`.
בטלפון: כרום → ⋮ → **"הוספה למסך הבית"**.

### שלב 2: השרת (`worker/`)
1. **מפתח Gemini (חינם):** https://aistudio.google.com/apikey
2. **Azure Speech (חינם, F0):** פורטל Azure → Create → Speech service → Pricing tier **Free F0** → מעתיקים Key ו-Region. קולות אמהריים: `am-ET-MekdesNeural` (אישה), `am-ET-AmehaNeural` (גבר).
3. **Cloudflare (חינם):**
   ```bash
   cd worker
   npx wrangler login
   npx wrangler secret put GEMINI_API_KEY
   npx wrangler secret put AZURE_SPEECH_KEY
   npx wrangler secret put SIGNING_SECRET      # מחרוזת אקראית ארוכה
   # לעדכן ב-wrangler.toml את ALLOWED_ORIGINS ו-AZURE_SPEECH_REGION
   npx wrangler deploy
   ```
4. לשים את הכתובת שהתקבלה ב-`app/config.js`.

בדיקה מקומית בלי מפתחות: `cd worker && node test.mjs`.

בלי Azure האתר עדיין עובד – הוא רק מקריא בקול של הטלפון (לרוב עברית, כי ברוב המכשירים אין קול אמהרי).

### שלב 3 (אופציונלי): בוט "הגשר" למתנדבים (`bot/`)
המבוגר שולח הודעה קולית/תמונה למספר אחד → זה מגיע למתנדב דובר אמהרית → המתנדב עונה דרך הבוט.
הוראות הקמה בהערות בראש `bot/server.js` ו-`bot/.env.example`. את מספר הבוט שמים בהגדרות האתר כ"מי עוזר".

## ⚠️ דברים שחשוב לדעת לפני שמתחילים עם אנשים אמיתיים

1. **פרטיות.** בשכבה החינמית של Gemini, Google רשאית להשתמש בתוכן לשיפור השירות (ויש בודקים אנושיים).
   לכן בתקופת הניסוי: מסמכים לדוגמה / מסמכים שהוסרו מהם פרטים מזהים, והסכמה קולית מודעת (יש מסך כזה).
   כשיש מימון – לעבור לשכבה בתשלום, שבה המידע לא משמש לאימון. לפי תיקון 13 לחוק הגנת הפרטיות, מידע רפואי ופיננסי הוא רגיש במיוחד – לבדוק משפטית לפני הרחבה.
2. **וואטסאפ ו-AI.** תנאי Meta מגבילים בוטים שה-AI הוא הפונקציה המרכזית שלהם. לכן הבוט כאן הוא **גשר לאנשים**, וה-AI נמצא באתר.
3. **תמחור וואטסאפ** משתנה (לפי המחקר מ-ChatGPT, מאוקטובר 2026 יש חיוב גם על הודעות שירות מעל מכסה חודשית). לבדוק בדף התמחור של Meta לפני שמרחיבים.
4. **מכסות חינמיות** של Gemini, Azure ו-Cloudflare מספיקות לפיילוט של עשרות משתמשים, לא לאלפים. התנאים משתנים – לבדוק.
5. **השרת פתוח לכל מי שיודע את הכתובת.** `ALLOWED_ORIGINS` חוסם אתרים אחרים בדפדפן, ו-`/api/speak` מקריא רק טקסט שהשרת חתם עליו. לפני פרסום רחב – להוסיף Rate Limiting ב-Cloudflare.

## מה חסר (לא קוד) – לפי תוכנית 90 הימים

- [ ] **ראיונות:** 15–20 מבוגרים. לשאול "מה המכתב האחרון שלא הבנת?", לא "היית משתמש בבוט?".
- [ ] **בדיקת איכות:** 25 מסמכים אמיתיים (בלי פרטים מזהים) + 30 שאלות מוקלטות. שני דוברי אמהרית בודקים כל תשובה.
- [ ] **הקלטות:** הנחיות קוליות קבועות ב-`app/audio/am/` (רשימה ב-`app/audio/README.md`).
- [ ] **שותפים:** טנא בריאות, טבקה, מכון פוירשטיין, מרכזים קהילתיים (למשל ראשון לציון).

bot/server.js                בוט וואטסאפ "גשר" למתנדבים
