# ቤተሰብ · משפחה

כלי חינמי למבוגרים יוצאי אתיופיה שלא קוראים וכותבים ולא רגילים לטכנולוגיה.
**עיקרון אחד: לא צריך לקרוא כלום.** כל דבר הוא תמונה גדולה + צבע + קול שמדבר אמהרית.

שני חלקים, שניהם בעלות 0 ₪:

| | מה זה | למי |
|---|---|---|
| `app/` | אפליקציית רשת שמותקנת על מסך הבית של הטלפון | המבוגר עצמו (בן משפחה מגדיר פעם אחת) |
| `bot/` | בוט וואטסאפ שמחבר מבוגרים למתנדבים דוברי אמהרית | מבוגרים שכבר יודעים לשלוח הודעה קולית |

## 1. האפליקציה (`app/`)

מסך הבית – 5 כפתורים ענקיים:

- 👨‍👩‍👧 **משפחה** – תמונות של הילדים/נכדים. נוגעים בתמונה → שומעים את השם → השיחה מתחילה.
- 🚑 **חירום** – מד״א 101, משטרה 100, כבאות 102, ובן המשפחה הראשון ברשימה.
- 💊 **תרופות** – תמונה של כל קופסה, מסודר לפי 🌅 בוקר / ☀️ צהריים / 🌇 ערב / 🌙 לילה (בלי לקרוא שעון). הזמן הנוכחי מסומן במסגרת צהובה.
- ✉️ **מכתב** – מצלמים מכתב (ביטוח לאומי, קופת חולים, עירייה...) והוא נשלח בוואטסאפ לבן משפחה / מתנדב שיסביר.
- 🎓 **ללמוד** – שיעורים קוליים צעד-אחר-צעד: לענות לשיחה, הודעה קולית, שיחת וידאו, **איך לזהות רמאים בטלפון**.

כל כפתור מדבר. סדר הקולות:
1. הקלטה של בן המשפחה בקולו (ממסך ההגדרות) – הכי טוב, קול מוכר.
2. קובץ מוקלט מראש ב-`app/audio/am/` (מתנדב מקליט פעם אחת לכולם – ראו `app/audio/README.md`).
3. הקראה אוטומטית של הטלפון (לרוב אין אמהרית → מקריא בעברית).

**הגדרות:** מחזיקים את ⚙️ (בפינה) 3 שניות – כדי שהמבוגר לא ייכנס בטעות. שם מוסיפים אנשי קשר עם תמונה, תרופות, מספר של עוזר למכתבים, ומקליטים קולות.

**פרטיות:** הכול נשמר רק בטלפון עצמו. אין שרת, אין חשבון, אין איסוף מידע.

### להריץ על המחשב
```bash
cd app && python3 -m http.server 8000
# לפתוח http://localhost:8000
```

### לפרסם בחינם (GitHub Pages)
1. למזג את הקוד ל-`main`.
2. ב-GitHub: **Settings → Pages → Source: GitHub Actions**.
3. הכתובת תהיה `https://<שם-המשתמש>.github.io/git-test/`.
4. בטלפון של ההורה: לפתוח את הכתובת בכרום → ⋮ → **"הוספה למסך הבית"**. מעכשיו זה נראה כמו אפליקציה ועובד גם בלי אינטרנט.

## 2. בוט הוואטסאפ (`bot/`)

הרבה מבוגרים כבר יודעים דבר אחד: **ללחוץ על המיקרופון ולדבר**. הבוט בנוי על זה:

1. המבוגר שולח הודעה קולית / תמונה של מכתב למספר של הבוט.
2. הבוט מעביר אותה למתנדבים, ועונה למבוגר בהודעה קולית באמהרית: "קיבלנו, נחזור אליך".
3. המתנדב שולח לבוט את מספר המבוגר → מעכשיו כל מה שהוא שולח (גם הודעה קולית) עובר אליו.
4. כל הודעת טקסט אחרת → הבוט שולח תמונת תפריט (1 🗣️ · 2 🎓 · 3 🚑) + הסבר קולי.

המבוגר צריך לשמור מספר אחד בלבד, והמתנדבים לא חושפים את המספר הפרטי שלהם.

### הקמה (חינם)
1. [developers.facebook.com](https://developers.facebook.com) → Create App → Business → מוסיפים **WhatsApp**.
2. מקבלים מספר בדיקה חינמי, `PHONE_NUMBER_ID` וטוקן. לשימוש אמיתי – מחברים מספר טלפון משלכם (SIM ייעודי) ויוצרים System User token קבוע.
3. מעלים את `bot/` לשירות אירוח עם שכבה חינמית שמריץ Node.js (למשל Render / Koyeb / Google Cloud Run – לבדוק את התנאים העדכניים).
4. מגדירים משתני סביבה לפי `bot/.env.example`.
5. ב-Meta: WhatsApp → Configuration → Webhook: `https://<השרת>/webhook` + אותו `VERIFY_TOKEN`, ולהירשם ל-`messages`.

**עלות:** כשהמבוגר פונה ראשון, התשובות ב-24 השעות הבאות חינמיות (הודעות שירות). זה בדיוק מה שהבוט עושה.
⚠️ **מגבלה חשובה:** גם למתנדב חל חלון 24 שעות – הבוט יכול לשלוח לו רק אם המתנדב כתב לבוט ביממה האחרונה. פתרון פשוט: המתנדב התורן שולח לבוט "בוקר טוב" כל בוקר. לבדוק את מדיניות התמחור העדכנית של Meta לפני שמרחיבים.

> לא להשתמש בספריות "לא רשמיות" שמחקות את וואטסאפ ווב – זה נגד תנאי השימוש והמספר עלול להיחסם.
